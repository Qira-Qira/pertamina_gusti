Kenapa BMKG masuk ke RESILIENT 3T-MBG?

Cuaca → Risiko Distribusi
Informasi cuaca digunakan sebagai salah satu input untuk menilai risiko perjalanan, terutama ketika rute menggunakan transportasi laut atau melewati wilayah yang sensitif terhadap hujan, kabut, dan kondisi jalan.
Catatan penting: website prototype ini tetap dapat digunakan offline. Saat internet tersedia, operator membuka halaman resmi BMKG untuk memperbarui informasi cuaca, lalu memasukkan status cuaca ke sistem sebagai data lokal.
